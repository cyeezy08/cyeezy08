# cyeezy08

**Security tooling and open-source projects**

I build tools for security teams and developers, with an interest in defensive security, authorized testing, and making security workflows more practical.

## Projects

- [SurfaceDiff](https://github.com/cyeezy08/surfacediff) — Tracks changes across external attack surfaces.
- [HostageLVX](https://github.com/cyeezy08/HostageLVX) — Helps validate dangling DNS and subdomain-takeover risks.
- [FenrirLVX](https://github.com/cyeezy08/FenrirLVX) — Maps WordPress exposure and correlates findings with known vulnerabilities.
- [LLM-bullshit](https://github.com/cyeezy08/LLM-bullshit) — Evaluates security-review agents and remediation workflows.
