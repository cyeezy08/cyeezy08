# Building things.

Go tools, internet infrastructure, security research, and an ongoing attempt to make messy signals useful.

The projects below are real code, real tests, and occasionally very stubborn bugs. Most of the work happens in the repos, not in this README.

## Leviathan X tools

| | Project | What it actually does |
| :-- | :-- | :-- |
| `01` | **[FenrirLVX](https://github.com/cyeezy08/FenrirLVX)** | WordPress component identification and offline advisory correlation, including coverage gaps. |
| `02` | **[HostageLVX](https://github.com/cyeezy08/HostageLVX)** | Checks DNS and provider evidence to classify dangling configurations on authorized assets. |
| `03` | **[surfacediff](https://github.com/cyeezy08/surfacediff)** | Turns asset inventories into reproducible snapshots and field-level change reports. |

## Bigger project

**[Leviathan X](https://leviathanx.org)** is the exposure-intelligence workbench I'm developing around source-backed observations, historical changes, and useful investigations. The standalone CLI tools above remain independently usable. The unified hosted product is a work in progress.

**Also building:** [kimi-k3-in-c](https://github.com/cyeezy08/kimi-k3-in-c) and [LLM-bullshit](https://github.com/cyeezy08/LLM-bullshit), independent model and evaluation experiments.
