# cyeezy08

**Go developer. Security tooling. Open source.**

I build practical tools for developers and security teams. My work focuses on defensive security, authorized testing, and making security workflows easier to run and understand.

## Projects

- [SurfaceDiff](https://github.com/cyeezy08/surfacediff): Tracks changes across external attack surfaces.
- [HostageLVX](https://github.com/cyeezy08/HostageLVX): Helps identify dangling DNS records and subdomain takeover risks.
- [FenrirLVX](https://github.com/cyeezy08/FenrirLVX): Maps WordPress exposure and correlates findings with known vulnerabilities.
- [LLM-bullshit](https://github.com/cyeezy08/LLM-bullshit): Tests AI-assisted security review and remediation workflows.
